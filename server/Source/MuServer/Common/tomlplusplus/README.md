# toml++: lectura de TOML

Header único vendorizado sin modificaciones desde https://github.com/marzer/tomlplusplus,
versión v3.4.0 (`toml.hpp`, SHA-256 `6b5172ad4dd6519aec67b919181fa7a38a2234131e5b2afa232dfe444819783e`).
Licencia MIT (`LICENSE`).

Lo usan los archivos de datos que escribe el operador (Fase 5: datos por mapa).
Se incluye con `TOML_EXCEPTIONS 0`: los errores vuelven como `parse_result`
con archivo y línea, sin excepciones.
